# Quick Start Guide

## Installation & Setup

### 1. Install Dependencies
Open a terminal in this folder and run:
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Your app will open at `http://localhost:5173`

### 3. Customize Your Content
See [CUSTOMIZATION.md](CUSTOMIZATION.md) for detailed instructions on:
- Adding your organization's information
- Adding books, events, and photos
- Changing colors and branding

### 4. Deploy (Make it accessible to everyone)
See [DEPLOYMENT.md](DEPLOYMENT.md) for step-by-step deployment instructions to:
- Vercel (Recommended - Easiest)
- Netlify
- GitHub Pages

✅ **Mobile-Friendly**: Works perfectly on phones and tablets
