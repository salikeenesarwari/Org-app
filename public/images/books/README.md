# Book Cover Images

Place your book cover images here.

## Recommendations:
- Size: 300x400 pixels (portrait)
- Format: JPG or PNG
- Keep file size under 200KB
- Use clear, high-quality images

## Naming:
- Use descriptive names: `book1-cover.jpg`, `abyat-cover.png`
- Match the filename with what you use in `books.js`
