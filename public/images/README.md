# Add your organization's images here

Place your images in this folder and reference them in the data files.

## Recommended Structure:
- `books/` - Book cover images
- `events/` - Event photos
- `gallery/` - Gallery photos
- `logo.png` - Organization logo

## Image Guidelines:
- Use JPG for photos (smaller file size)
- Use PNG for logos and graphics with transparency
- Keep images under 500KB when possible
- Optimize images before uploading (use tools like TinyPNG.com)
