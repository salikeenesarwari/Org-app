# How to Host PDFs on Google Drive

Since Vercel has limitations with serving large PDF files, here's how to host them on Google Drive for free:

## Steps:

1. **Upload PDFs to Google Drive:**
   - Go to https://drive.google.com
   - Create a folder called "Faizan-e-Sarwari Books"
   - Upload all 5 PDF files to this folder

2. **Get Shareable Links:**
   For each PDF:
   - Right-click on the PDF → "Share" → "Get link"
   - Change permission to "Anyone with the link can view"
   - Copy the link (it will look like: https://drive.google.com/file/d/FILE_ID/view?usp=sharing)

3. **Convert to Direct View Link:**
   Replace the link format from:
   ```
   https://drive.google.com/file/d/FILE_ID/view?usp=sharing
   ```
   To:
   ```
   https://drive.google.com/file/d/FILE_ID/preview
   ```

4. **Update the book links in the app** - I'll help you do this once you have the links!
